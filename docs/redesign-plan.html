Re-skinning Agentic Loops in the Tokenomy design language

A plan to retire the neon-cyberpunk theme and adopt Tokenomy's calm, textbook-authority system: warm paper & ink, a single slate-blue accent, Inter + JetBrains Mono, 1px ledger borders, and restrained, purposeful motion. This page is itself rendered in the proposed system — toggle light/dark in the top-right and scroll for live component samples and a full hero mockup.

01 · the shift

From "sci-fi terminal" to "engineering textbook"

The current site leans on neon glows, chamfered clip-path corners, a grid+scanline overlay, gradient text, an all-monospace body, and the Rajdhani display face. It reads as marketing / sci-fi. Tokenomy deliberately rejects that — its north star sits between Bartosz Ciechanowski, Stripe Docs, and Anthropic research: "textbook authority, engineering pragmatism, no marketing overhead."

That vibe is a far better fit for Agentic Loops' own thesis — building agents is engineering, not magic. The visuals should make the same argument the copy does: calm, precise, credible. The table below is the core philosophy swap.

06 · motion

Animation language

Tokenomy's rule: CSS transition → motion.dev → anime.js, in order of increasing expressiveness, and motion only when motion is the point. Every ambient animation is viewport-gated and has a reduced-motion fallback that renders the terminal frame statically.

  • CSS — hovers, focus rings, the subtle card lift, link underlines. Replaces glow-pulse / shimmer / float.
  • motion.dev — React-island work: section reveals (replacing ScrollReveal's slide-ins with a calm fade+8px rise), accordion expand, theme cross-fade.
  • anime.js v4 — the hero loop's orbiting token and any SVG path-draw. Wrap in createScope with a reduce media query; scope.revert() on cleanup.
Hard cuts from the current site: the fixed grid+scanline overlay, gradient-blur blobs, glow box-shadows, translateX(4px) button nudge, and the custom cyan scrollbar. Keep prefers-reduced-motion honored everywhere (already present in global.css).
07 · execution

Phased migration plan

Astro + React + Tailwind stays. The work is concentrated in tokens, global.css component classes, and removing decorative markup from a handful of components. Estimated 2–3 focused days.

P0
Tokens & fonts. Replace the :root/[data-theme="light"] blocks in global.css with the Tokenomy token set; switch theme strategy from [data-theme] to .dark on <html> (update themeStore.ts + ThemeScript.astro). Add @fontsource/inter + @fontsource/jetbrains-mono; drop Rajdhani/Azeret + the Google Fonts link. Update tailwind.config.js font families and color mappings.
P1
Primitive classes. Rewrite .btn-primary/.btn-secondary, .card (+ color variants → viz palette), .badge/.status-badge/.chip, .code-block, .icon-box, .section. Delete all clip-path bevels, glow shadows, .gradient-text, .corner-accent, gradient blobs, scanline/grid body::before, custom scrollbar.
P2
Layout shell. Header.tsx → quiet sticky nav (mono brand glyph, no glow). Footer.tsx → host the theme toggle (Tokenomy pattern). Set max-widths (1080 home, ~860 prose).
P3
Sections. Hero.tsx (accent rule + line-art loop), About.tsx (drop uppercase Rajdhani beliefs), Topics.tsx (viz-palette module cards), Team / RepoSection / Subscribe. Replace ScrollReveal slide-ins with a calm fade-rise.
P4
Content & polish. Course/MDX prose styles to Tokenomy reading rhythm, KaTeX if formulas appear, Search popover restyle, OG images, favicon to bracket-glyph mark. QA both themes + reduced-motion + AA contrast.
